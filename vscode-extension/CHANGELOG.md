# 更新日志

本文件记录 DCODE for VS Code 扩展的版本变更。版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.2.1]

### 新增

- **资源管理器右键「加入 DCODE 上下文」**：在资源管理器中右键任意**文件或文件夹**即可一键加入对话上下文，支持 Ctrl / 框选多选；文件夹会浅层展开其直接子文件，自动跳过二进制与超大（> 2MB）文件，单次最多 50 个，统一转为相对路径 chips 回填到面板（更省 token）。
- **面板内「+ 文件 / + 文件夹」按钮**：通过 VS Code 原生选择器挑选文件 / 文件夹加入上下文，规避 Webview 拖放被沙箱清洗的限制，100% 可靠。
- **点击切换 供应商 / 模型 / 权限模式**：面板顶部状态栏三个「药丸」可点击弹出下拉选择器，复用内核 `/provider`、`/model`、`/plan` 逻辑并持久化。

### 变更

- **彻底移除「从资源管理器拖文件进面板」的拖放交互与遮罩 UI**：VS Code Webview 出于安全会清洗拖放数据（多数平台拿不到文件 URI、不可靠），故统一改用右键 / 按钮入口；同步清理了相关的拖放遮罩样式死代码。
- 同步更新扩展 README 与根项目 README 中的功能说明。

## [0.2.0]

### 新增

- 右侧辅助侧边栏对话面板（流式输出、思维链、Markdown 渲染、工具调用折叠卡片）。
- 选中代码右键「加入上下文 / 解释 / 修复 / 重构 / 加入对话」。
- 代码块一键「复制 / 预览 diff / 应用」到编辑器。
- 斜杠命令补全菜单（复用 CLI 命令系统）。
- IDE 内逐次权限授权（允许一次 / 总是允许 / 拒绝）。
- 通过 `dcode --ide-server`（NDJSON over stdio）完整复用 Agent 内核，可打包为自带内核的 `.vsix`。
